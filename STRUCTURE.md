# Project structure

AI Usage shows the usage limits (percent used, reset time) of one AI coding agent at a time, Claude
Code or Codex, and can keep the computer awake. On Windows it draws a quarter-disc widget in a
screen corner. On macOS and Linux it draws the usage rings as the tray / menu-bar icon, with a popover
attached to the icon. Everything else lives in a settings window and the tray menu. Go (Wails 3) does
all the work; the Svelte frontend only renders what the bound services and events give it.

```text
repo/
├── main.go           embeds frontend/dist, calls app.Run
├── internal/         all Go logic, one package per area (below)
├── frontend/         Svelte 5 + Vite + Tailwind 4; bindings/ is generated by `make bindings` (committed)
├── build/            Wails build assets (icons, manifests, installers); config.yml drives `wails3 dev`
├── scripts/          build-windows.bat, build-mac.sh, build-linux.sh: app + installer/packages per OS
├── Taskfile.yml      Wails build tasks (called by `make build`, `make package` and scripts/); reads the version
└── Makefile          dev commands (run `make help`)
```

## Go packages (`internal/`)

| Package | Responsibility |
| --- | --- |
| `provider` | Contract: `Provider`, `Limit`, `Kind`, `Snapshot`, `Status`, sentinel errors. |
| `provider/claude` | Reads the token Claude Code keeps (`$CLAUDE_CONFIG_DIR` or `~/.claude/.credentials.json`; macOS Keychain first) and calls `GET https://api.anthropic.com/api/oauth/usage` (undocumented). Shows only `five_hour`, `seven_day`, `seven_day_{opus,sonnet}`. Polls every 2 min. |
| `provider/codex` | Reads the last `token_count` event with `rate_limits` from the newest `$CODEX_HOME/sessions/YYYY/MM/DD/rollout-*.jsonl` (tail only). Polls every 30 s. No network. |
| `poller` | Polls the active provider only. Keeps a per-provider cache, maps errors to statuses, backs off on 429 (max 15 min). |
| `config` | `config.json` preferences, atomic save. Invalid fields fall back to the defaults. |
| `wakelock` | Wake-lock state machine and `Service` (ported from wake-lock, without IPC). |
| `inhibit` | OS sleep inhibitor: Windows `SetThreadExecutionState`, macOS `caffeinate`, Linux logind + ScreenSaver D-Bus. |
| `autostart` | Start at login: Windows HKCU `Run` value `ai-usage`, macOS LaunchAgent `com.jacopofilonzi.ai-usage`, Linux `ai-usage.desktop`. |
| `logging` | slog to `<user cache>/ai-usage/ai-usage.log` (+ stderr), rotated past 1 MiB. |
| `i18n` | Go EN/IT strings for the tray menu and tooltip; OS language detection. |
| `trayicon` | Pure-Go PNG tray icons: Windows gauge glyph + wake dot; macOS/Linux usage rings. |
| `platform` | The only `runtime.GOOS` use, cursor position (Windows), tray icon size. |
| `tray` | Wails system tray: menu, icon, tooltip/label. The same entries form the widget's context menu. |
| `app` | Wiring, the bound services, the settings and popover windows, the corner widgets (`widgets_windows.go`). |

`app/contract.go` is the contract with the frontend: types, event names, window/view names, widget
geometry. Changing it means regenerating the bindings and updating the frontend in the same change.

### Bound services and events

Services (generated into `frontend/bindings/.../internal/app`):

- `UsageService`: `Providers`, `Snapshot`, `SetProvider`, `Cycle`, `Refresh`
- `SettingsService`: `Get`, `Save`, `SetAutostart`, `Open`, `Quit`
- `WakeLockService`: `Status`, `Start(minutes)` (0 = indefinitely), `Stop`, `SetKeepUnlocked`
- `WidgetService`: `Geometry`

Events Go → frontend: `usage:snapshot` (Snapshot), `wakelock:status` (Status),
`settings:changed` (Settings), `widget:hover` ({window, hover}).

### Windows

Every window loads the same bundle; `/?view=` picks the view.

| Window | View | Notes |
| --- | --- | --- |
| `settings` | `settings` | hidden at start; closing hides it; opened from the tray, a second launch, or at first run with no agent |
| `popover` | `popover` | macOS/Linux only, attached to the tray icon |
| `widget-<screen>` | `widget` | Windows only, one per target screen, 200×200 DIP, transparent, always on top, click-through until the cursor reaches the corner disc |

### Data and state

| What | Where |
| --- | --- |
| Preferences | `<user config dir>/ai-usage/config.json` → `{provider, corner, monitor, language, poll_seconds, keep_unlocked}` |
| Log | `<user cache dir>/ai-usage/ai-usage.log` (+ `.log.1`) |
| Start at login | read from the OS, never stored in the config |

Usage snapshots and the wake lock live only in memory. Tokens are never stored.

## Frontend (`frontend/src`)

| File | Responsibility |
| --- | --- |
| `main.ts` | routes `?view=widget\|popover\|settings`, starts the store |
| `app.css` | colour tokens (light/dark), Tailwind `@utility` classes |
| `lib/state.svelte.ts` | the `app` store (runes): initial load from the services, then kept current by events; actions |
| `lib/i18n.ts` | EN/IT dictionaries (`it` typed from `en`) |
| `lib/format.ts` | limit labels, percentages, countdowns, status messages, colour thresholds |
| `lib/log.ts` | `logError`, the only console output |
| `components/` | `Rings` (full/quarter), `Toggle`, `CornerPicker`, `WakeIcon` |
| `views/` | `Widget`, `Popover`, `Settings` |
